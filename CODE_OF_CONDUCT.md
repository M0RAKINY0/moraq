# Code of conduct

moraq follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, discussions and any other project space.

In short: be respectful, assume good faith, and keep criticism about the code, not the person. Harassment, insults and personal attacks get you removed from the project.

## Reporting

Contact the maintainer, [@M0RAKINY0](https://github.com/M0RAKINY0), through the email on their GitHub profile. Reports stay private. The maintainer decides on action using the enforcement guidelines in the Contributor Covenant.
